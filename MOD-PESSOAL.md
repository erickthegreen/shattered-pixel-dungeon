# Shattered Dungeon Personalizado (Android)

Mod pessoal baseado no Shattered Pixel Dungeon. Esta branch mantem a branch master original intacta.

## Alteracoes
- Terceiro espaco para anel: anel principal + anel adicional + espaco misto (que pode ser usado para anel ou artefato).
- 200 Pergaminhos de Melhoria na mochila ao iniciar uma nova partida.
- Um exemplar identificado de cada um dos 12 tipos de anel na geracao do primeiro andar. Os aneis sao distribuidos como itens de chao durante a geracao do andar (nao necessariamente junto a entrada).
- Nome e identificador do aplicativo diferentes dos originais.

## Gerar o APK pelo celular
1. No GitHub, abra **Actions** e habilite workflows, se solicitado.
2. Abra o workflow **Compilar APK - Shattered Dungeon Personalizado**.
3. A compilacao inicia quando a branch e atualizada; voce tambem pode usar **Run workflow**, selecionando a branch **mod/aneis-e-pergaminhos**.
4. Abra a execucao concluida e procure **Artifacts > Shattered-Dungeon-Personalizado-APK**.
5. Baixe o ZIP do artifact, extraia o APK e instale no Android.

A compilacao ainda precisa ser validada pelo GitHub Actions. Se falhar, consulte os logs da execucao.
Os saves do jogo oficial nao sao compartilhados com este app. Preserve backup dos dados originais.
